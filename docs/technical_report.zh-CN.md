# TMASR-Net：高效连续图像序列自监督重建

更新于 2026-10-12。[全部已完成实验](../results/README.md)、[实验目录](../results/experiments.csv)和[最终指标](../results/results.csv)提供完整数值。本报告解释核心贡献，英文论文保留在本地。

## 设计与贡献

TMASR-Net（Temporal-Mean-Anchored Sub-pixel Residual Network；G4）从邻帧预测被排除的中心帧。它适应性整合 DeepInterpolation 的连续序列学习思想、全分辨率时间均值、邻帧联合空间重排与残差修正，从带噪序列自监督学习，无需干净训练参考。邻帧在全分辨率上的均值构成输出锚点；PixelUnshuffle(2) 将输入重排为四个空间相位，紧凑 U-Net 在半分辨率网格上学习残差。编码器宽度为 8/16/32、瓶颈 64，拼接跳连连接 32/16/8 解码器。零初始化的四相位头使初始输出等于时间均值，PixelShuffle 恢复残差后与锚点相加。

贡献落在完整重建框架及其质量—参数—运行速度表现；时间平均、像素重排和残差学习分别作为已有的设计基础。匹配 w30 时，G4 和原版架构 DI 复现均使用排除中心的 60 帧输入。原版采用 64/128/256/512/1024 通道层级并直接预测。

## 对照说明了什么

225 项 G1–G5 训练在三记录、三窗口、五种子上交叉比较目标函数、计算位置和深度。MSE 相对 MAE 在全网格和子像素网格上分别增加 0.2450/0.2435 dB；相同目标函数下的位置变化为 -0.0020/-0.0036 dB，同时平均卷积成本从 5.334 降至 1.464 GFLOPs。主要重建变化由目标函数解释，算术节省由计算位置解释。

405 项容量训练比较宽度、深度和卷积单元，另有 135 项确定性基线评价。结构、窗口及两种子的 4× 加宽实验说明容量变化如何恢复质量及其代价。所有正常完成的对照均公开，包括没有改善 G4 的结果。

干净参考仿真中 G4/G2 为 42.22/44.08 dB，相对幅值误差为 0.390/0.491。标准局部 SSIM 与全帧 gSSIM 分列；G4/G2 五种子均值为 0.7012/0.7005、0.9711/0.9710、0.6008/0.6013。Suite2p 检测 ROI 从 245/434/412 变为 437/816/1176，迹相对噪声中位数同时降低。仅使用过去帧 (-2,-1) 时，与对应对称输入的验证 PSNR 差在 0.025 dB 内。固定设计在 02.00/04.00 上分别重新训练，得到 26.6323/34.6562 dB，称为“新增记录验证”。

## 测量定义

真实 PSNR 以带噪中心帧的强度范围计算，clean PSNR 使用仿真真值。历史评估片段此前被查看过；每项指标保留划分、种子数和聚合方式。ROI 数量和迹波动描述检测结果集，不能视为检测准确率。

DI/G4 的 3.7–4.2 倍独立前向提速使用 RTX 5070 Ti、batch 1、FP16、channels-last、20 次预热和 100 次计时，以三种子中位时间的均值求比。历史 G1–G5 计时继续注明 RTX 4060 Laptop。修正后的 w2 完整流程覆盖 TIFF 读取、预处理、传输、前向及 CPU 输出消费；G4 两遍处理为 8.26–9.81 ms/帧。该诊断中 G4 相对 G2 没有一致的完整流程优势，未来帧采集等待另列。

Conv3d 算术计入时间核。适配的 DeepCAD-RT 使用仅空间池化和时间均值输出头，参数为 1,459,585，两个真实尺寸下为 254.6110/242.8005 GFLOPs。缺测项留空，旧零值占位由实算卷积成本替代。

## 事件 ROC 更正（2026-10-12）

原始帧号不能直接作为预测数组行号。已对事件搜索窗与基线窗统一使用帧号映射，并用现有权重重评，未训练。G4 在 Poisson peak 16/32 下 AUC 均为 1.000000，四方法范围为 0.997646–1.000000。各方法灵敏度均为 100%，95 分位负例阈值对应的实测 FPR 为 4.802%–5.085%，不能写成严格 FPR≤5%。完整精度、阈值和描述性 bootstrap 区间见[结果表](../results/results.csv)，方法与解释见[更正说明](event_roc_correction.md)。接近上限的 ROC 不区分瞬态幅值保真；幅值和峰时是独立指标。
